## 差异与未通过项

1. **后端为替代实现。** 单进程、内存状态、单地区/实例，JSON 兼容增量；没有原站二进制背压、弹性地区分配和长期持久化。选择座位、距离容差、重连保留、咖啡交接与施工生命周期不是原服务源码一致性声明。
2. **活动分支尚未全对齐。** 咖啡完整多人交接、所有园中座位/垃圾桶、本地已实现施工跨房间溢出和全房间完成，但原站精确分配与结束时序未对齐；咖啡、席位与垃圾桶的完整分支未逐项原站对照。许愿灯代码与素材已发现，但本轮原站快照未开放可写状态；本地明确返回 unavailable，没有生成一个近似活动冒充通过。
3. **设备和时段证据缺失。** 实际 Safari 17.6 的 WebDriver 因未开启“允许远程自动化”无法建立会话，见 `comparisons/safari/result.json`。真实 iPhone Safari、Android Chrome 没有实测；Chrome 触屏模拟不替代真机。韩国时间 05:00/18:00 早晚课及昼夜切换全过程未在原站实际取证。
4. **部分异常与边界仍未穷尽。** 全部地形边界/碰撞/音区、所有设置持久化、长期后台、弱网参数及活动与迟到消息的全组合未覆盖。已测路线和有限失败恢复不能推导这些分支通过。
5. **原站存在不可得的代码引用。** `heart-sutra-v1.mp3` 是代码中遗留/未触发地址，源站返回 404；当前实际诵念使用已保存的 `temple-chant-review-v1.mp3`。对模块相对地址误抽取出的 `/assets/audio/moktak...` 已解释为 document.baseURI 引用，正确 `/audio/moktak...` 已保存并实测。未将 404 HTML 保存成假资源。
6. **支付只做本地模拟。** 原界面入口保留，点击支付按钮进入明确标识的本地反馈页面，没有进行真实付款，不能视为原版支付通过。

入口 HTML 的浏览器响应与普通 HTTP 客户端响应仅有 Cloudflare 注入统计脚本差异；两种原始哈希和原因已登记。当前入口/主包复核无应用版本变化。source map 引用未发现可用内容，对入口、主包和 presence Worker 的 `.map` 实际探测均为 404，没有假称恢复开发源码。
