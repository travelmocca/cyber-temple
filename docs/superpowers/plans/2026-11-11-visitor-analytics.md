# 匿名访客统计与口令报表

用户要求增加历史用户、PV、UV统计，并通过 `/api/report` 查看；已明确选择口令保护。当前没有账号登录，按匿名浏览器统计访客，不能冒充实名人数或回补过去未采集的数据。

范围：累计/今日PV、UV、入寺人数与次数、北京时间近30天记录；页面刷新计新PV，分类/换批不计新PV，实际场景就绪才计入寺。查看报表和API/静态文件请求均不计PV。匿名标识保存在浏览器本地，清除或跨设备会成为不同访客。
