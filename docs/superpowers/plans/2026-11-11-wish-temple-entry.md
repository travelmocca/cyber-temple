# 祈愿选寺入场实施计划

目标为在934bda7汉化镜像上接入八类祈愿、五寺推荐与换批。寺院共用现有场景，场景仅读取山门匾额文字。

采用 writing-plans 技能整理本计划，使用 frontend-design 技能设计入场界面。入口采用纸色、松绿与金色细线，适配桌面及手机。

- [x] 先为候选过滤、换批去重、耗尽及目录完整性编写测试，确认失败。
- [x] 在 mirror/entry 下实现独立目录、抽样状态与入场页面。寺院资料从已整理目录迁移，显示两字分类。
- [x] 通过原哈希补丁机制替换HTML加载入口及山门匾额的固定文字，保持只读基准。
- [x] 扩展HTTP静态挂载以提供入场模块，沿用现有路径校验。
- [x] 同步本地化生成器，确保重新生成中文补丁后仍可重复生成入场补丁。
- [x] 执行单元、HTTP及资产完整性校验，桌面与手机实测完整入场流程和场景原有操作。
- [x] 开发后由两个子agent分别审查实现与验收，修复发现并复核。

本次不修改场景活动、身份、协议或多人房间规则。所有寺院继续使用同一个游戏入口。前端抽样采用类型匹配后的等概率随机，会话内按类别保留进度。
