# 游戏简体中文本地化

目标：在当前 `mirror/` 游戏上完成菜单、地图、动态提示、无障碍标签、可编辑场景文字、加载/退出及模拟支付页面的简体中文本地化，并提交到现有 `main` 分支。

方案：保留原始发布基准，中文词典单独存放。构建工具解析已登记版本的 JS 字符串和模板文本，仅对文本生成带前后哈希和精确位置校验的批量编辑补丁；不改标识符、表达式、协议类型、场景几何和活动规则。图片贴图、音频及原始授权文件保留原样。字体使用浏览器现有 CJK 回退，不增加外部请求。

1. 盘点原始文字；先加入中文入口和批量文本补丁的失败测试。
2. 翻译独立词典，覆盖所有已盘点文本片段，保留品牌与署名来源。
3. 扩展已有补丁校验器并生成中文补丁；本地模拟支付和默认访客名称使用中文。
4. 更新界面测试的文字选择器。原行为基线文件不重写，只在断言中显式归一已授权的中文文案差异。
5. 运行格式、资源、协议/HTTP 差分、中文覆盖和完整浏览器回归；检查桌面/移动布局及动态文字，保存截图。
6. 更新当前语言说明，重启预览；创建新提交并推送 `origin/main`，核对远端提交。

实现与验证已完成：588 条词典、4 项中文补丁、31 项单元/集成测试和 7 项 Chrome 回归通过。原版基准和历史 fixtures 不变；详见 `RECON/zh-CN-2026-11-11/report.md`。提交后以 Git 记录及远端提交核对为准。
