# 访问统计与口令报表

访问 `https://temple.hiwushuang.me/api/report`，输入部署时配置的查看口令即可查看。代码提供该路由，不会自动更改公网服务的运行环境或持久化卷。

## 配置与数据保留

需要Node.js **22.13.0或更新版本**，使用内置 `node:sqlite`，没有新增npm依赖。Node 22可能输出SQLite实验性功能提示，功能测试已通过当前22.21.1环境。

| 环境变量 | 配置 |
| --- | --- |
| `REPORT_PASSWORD` | 由管理员自行设置，12至256字符。不得放进前端、Git或URL。未配置/长度不符时，报表返回503，采集仍继续 |
| `ANALYTICS_DB` | 可选，默认项目根目录 `data/analytics.sqlite`；生产建议使用数据卷上的绝对路径 |

服务不会自动读取 `.env`。若在本机使用环境文件，可复制 `.env.example` 为私有 `.env`、填写口令并限制文件权限，再用 `node --env-file=.env server/index.mjs` 启动；也可在部署平台直接设置上述环境变量后正常 `npm start`。

SQLite文件保存在静态目录之外，生产默认落盘；程序化创建的测试服务默认内存库。普通服务重启后数据保留；**容器重建/代码重新部署需要持久化挂载数据库所在目录**，否则临时文件系统中的历史会丢失。数据库及WAL/SHM文件已被Git忽略，也不会被静态HTTP服务提供。

以部署平台为例：将持久化目录挂到容器 `/data`，设置 `ANALYTICS_DB=/data/analytics.sqlite`，保证运行用户有写权限。不要把该目录放在 `site/` 或 `entry/`。备份可使用SQLite的备份工具；直接复制主文件前先正常停止服务，避免漏掉运行中的WAL数据。删除数据文件会重置历史，仓库不提供公共清空接口。

CDN和反向代理必须让 `/api/analytics`、`/api/report`及其子路径直达Node，禁止缓存报表和上报接口。统计响应已声明no-store，但CDN强制缓存规则仍需管理员排除。若HTTPS由代理终止，应覆盖并转发 `X-Forwarded-Proto: $scheme` 及原Host，确保查看会话的Secure标志正确；不要把外部客户端传入的转发协议值原样信任。

## 统计口径

- **累计PV**：页面真实打开/刷新一次记一次；从浏览器往返缓存恢复也计一次。选愿、换批、看介绍和游戏动作不重复增加PV。
- **累计UV**：按当前站点浏览器localStorage中的随机标识去重。不是账号数，也不是真实人数。同一个人跨设备、浏览器、隐私窗口或清除存储会成为不同访客；禁用存储时标识只能维持当前文档，UV会偏高。
- **入寺次数/人数**：真实场景就绪且入场浮层移除后记录；点击进入但加载失败不算。人数按同一匿名浏览器标识去重。
- **今日和近30天**：使用服务器收到事件时的北京时间（Asia/Shanghai）。每日UV不能相加作为累计UV；累计覆盖数据库保留的全部历史。
- **启用前的日期**：显示“未采集”，JSON对应指标为null且collected为false，避免误认为历史上确实0访问。
- **报表、API、图片及脚本请求**：均不计PV。普通只抓HTML而不执行JS的爬虫不计入。

数据从功能启用后开始采集，之前没有记录的历史不能补造。被拦截的埋点、网络故障或未执行JS会造成漏计；标识可被客户端伪造，统计不是实名或独立审计数据。

只保存事件ID、随机访客ID、页面访问/入寺类型、接收时间及日期；不记录账号、IP访问历史、设备指纹、心愿内容或口令。登录限速临时在内存中使用连接地址，不写入统计数据库。

## 查看与保护

`/api/report` 为中文HTML报表，包含累计/今日卡片、入寺统计、近30天记录和手动刷新。登录后也可访问 `/api/report?format=json` 获取相同的聚合数据。两者都不返回逐访客明细。

口令通过POST提交，验证后发放8小时签名HttpOnly、SameSite=Strict Cookie；HTTPS代理正确配置时设置Secure。错误口令按连接地址限次，连续8次失败后10分钟内拒绝尝试；代理后的请求可能共享同一个连接地址。修改部署口令并重启会让旧签名失效。退出查看清除当前浏览器会话；生产应使用HTTPS。

埋点模块异步隔离加载，用sendBeacon/keepalive传小事件，不等待上报完成再入寺。事件ID在数据库幂等去重；报表或采集失败不会改变游戏逻辑。
