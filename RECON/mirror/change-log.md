# 本轮变更与恢复记录

## 保护与隔离

当前分支为 `codex/sansa-experience`。开始时根目录工程和证据均未跟踪；未依赖空分支保护这些文件，先制作 `.snapshots/pre-mirror-2026-11-11.tar.gz`，SHA-256 记入 source-version.json。`src/`、`server/`、`public/` 和旧依赖/测试保留，新运行工程只建在 `mirror/`。

原有 4174 和 4180 监听保留。初期取证使用 4190；最终预览改为 4191（标准 Fetch 的受限端口兼容性），历史取证 URL 保持原值。回归与干净目录测试申请临时端口。没有部署到远程服务器，没有公开发布、推送或提交整个未跟踪工作区。

## 冻结与资源

本轮从原站实际响应建立 baseline，再由引用发现补齐 107 个文件。入口/主包复核一致；HTML 的 Cloudflare 请求上下文注入差异单独记录。纠正 document.baseURI 音频引用；遗留 heart-sutra 地址实际 404，保留缺口。存在的源文件与 manifest 哈希校验一致，没有用错误 HTML 或近似素材补齐。

工作副本的 3 项补丁依次移除入口统计、改两个支付链接。原始程序、字体、场景和素材保持只读基准；不将第三方汉化镜像作为当前版本。

## 服务与回归

按当前 village-1 客户端 schema 实现本地服务：20×50 房间、真实访客、24 坐垫中的合法空位、动作、上香 FIFO/租期、复连、咖啡和施工。以失败测试建立排他席位、重复请求、队首清理、杯子复连保存和非法请求边界，再补实现。没有虚拟访客服务。最后补齐无参数首页的自动分房，并增加默认入口真实浏览器回归，避免只验带 room 参数的地址。

联调中修复上香近场初值过严、队尾加入重置队首状态、在线咖啡制作后未自动交杯和短断线丢杯等本地问题。另按原客户端 delivery 响应补齐本地施工跨房间溢出和全房间完成，验证重复交付不加两次。原站正确规则仍缺完整观测的部分标为替代，未声称后端源码一致。

## 真实浏览器取证

早期固定等待不能证明地图到达，礼拜/咖啡按钮的 accessible name 会随模式改变。保留失败取证，再采用实际目标坐标、真实输入、显式站起移动和正确状态断言。PNG/录像未编辑。

另采 1920×902 的四类视觉样板与整圈环视、12 地点往返、原站/本地上香、个人诵念和咖啡。设备结果区分桌面 Chrome、触屏模拟、实际 Safari 驱动失败和未取得的真机。未把本地改时钟当作原站时段证据。

独立静态模式的补验晚于服务实现，时间顺序与原计划不同，具体记录 `network/static-only.json`；补验确认静态请求无缺失，必须有 `/presence/village` 才能完成入场。
